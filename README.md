# ChargeOps 充电站选址与扩容决策平台

ChargeOps 是一个面向充电网络运营商、园区和商业地产公司的充电设施选址与扩容决策平台。

系统将公开充电站数据、候选站点数据、区域指标和充电建设知识库结合起来，通过 5 个业务 Agent 生成区域覆盖分析、竞争分析、候选地址评分、扩容建议和政策匹配结果，并在前端提供可追溯的 RAG 证据。
